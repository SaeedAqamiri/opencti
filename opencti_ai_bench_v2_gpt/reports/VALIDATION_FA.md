# گزارش کنترل بستهٔ نسخهٔ دوم

این گزارش فقط نتیجهٔ کنترل کد مرجع و مسیر اتصال نمونه است؛ **هیچ مدل زبانی، OpenCTI زنده یا MCP واقعی با آن ارزیابی نشده است**.

## کنترل‌های انجام‌شده

| کنترل | نتیجه |
|---|---|
| تست‌های واحد و منفی داور/gateway | ۶۱ از ۶۱ موفق |
| اعتبارسنجی schema کیس‌ها | هر ۷۲ رکورد معتبر |
| اعتبارسنجی schema پاسخ‌های مرجع | هر ۷۲ رکورد معتبر |
| تطبیق مستقل queryهای مرجع با گراف | بدون mismatch در ۱۲ NLQ |
| یکپارچگی داده | ۷۱ موجودیت، ۷۱ رابطه، ۸ سند؛ ارجاع شکسته یافت نشد. |
| فایل تبادل STIX آزمایشی | ۱۵۳ آبجکت؛ ساختار JSON و ارجاع‌های داخلی بررسی شد. |
| تست اتصال subprocess و ابزار | C01 با حل‌کنندهٔ قطعی، سه تکرار موفق |
| رابط راهنمای HTML | بازبینی دسکتاپ و موبایل؛ overflow افقی صفحه مشاهده نشد. |

گزارش خام تست‌ها در `unit-tests.txt` و نتیجهٔ ماشینی در `validation.json` است. نمونهٔ پاسخ C01 در `smoke-c01-answer.json` قرار دارد. برای بازتولید trace دارای امضای قابل‌اعتبارسنجی، دستور smoke در README را در محیط خود اجرا کنید؛ کلید امضای اجرای تهیه‌کننده در بسته قرار ندارد.

## موارد اجرا‌نشده و مرز تفسیر

validator کامل STIX در محیط آماده نبود و نصب وابستگی به علت محدودیت دسترسی شبکه انجام نشد. بنابراین نتیجهٔ JSON و reference integrity را معادل اعتبارسنجی کامل STIX یا موفقیت import در OpenCTI ندانید.

نمونهٔ `local_chat_agent.py` ارائه شده، ولی اتصال آن به مدل واقعی آزمایش نشده است. token usage، کیفیت متن، موفقیت تحقیق CTI، مجوز پلتفرم واقعی، parity با MCP و حافظه چندسشنی اندازه‌گیری نشده‌اند.

هیچ نتیجه‌ای برای مدل قبلی کاربر یا snapshotهای واقعی ATT&CK/OTX ادعا نشده است. موفقیت حل‌کنندهٔ قطعی C01 فقط تست زیرساخت است و نباید با عنوان «Agent success=100%» منتشر شود.
