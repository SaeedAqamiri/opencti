# منشأ محتوا و منابع

## U1 — مبنای کار کاربر

**AI-Benchmark-Report.pdf**، فایل بارگذاری‌شده توسط کاربر، ۱۰ صفحه، تاریخ درج‌شده در گزارش ۱۷ سپتامبر ۲۰۲۶.

از این فایل این موارد گرفته شده‌اند: نام سه suite و پنج فاز، شش اکشن متنی، دسته‌های گزارش/بینش/NLQ، نام ۲۱ تست قبلی، قرارداد artifact قدیمی و محدودیت‌های ذکرشده در آن. صفحات ۱ تا ۲ دامنه و داده، صفحات ۳ تا ۷ کیس‌ها، صفحه ۸ متریک‌ها و صفحات ۹ تا ۱۰ وضعیت را شرح می‌دهند.

این فایل **شامل کد منبع grader و JSONهای snapshot نیست**. تعدادهای واقعی ATT&CK و OTX، موفقیت import، کیفیت مدل و نتایج اجرای قبلی در این بسته مستقلاً تأیید نشده‌اند. نام legacy «nlq-zebrocy-mitigations» عیناً برای traceability حفظ شده، هرچند سؤال توصیف‌شده درباره Phishing است.

## طراحی جدید این بسته

۷۲ کیس مصنوعی، گراف ساختگی، مثال‌های TEST، پاسخ‌های مرجع، قواعد سخت‌گیرانه نمره‌دهی، متریک‌ها، gateway، schemaها، rubric، probeهای خلاف‌واقع و برنامه توسعه، **طراحی پیشنهادی جدید** هستند. این‌ها استخراج مستقیم از گزارش کاربر یا مشخصات رسمی OpenCTI نیستند.

AST موجود در query.schema.json قرارداد خود بنچمارک است، نه API مستند OpenCTI. نام suiteها مشترک است، اما نتایج مصنوعی را نباید به نتایج واقعی قبلی متصل یا با آن‌ها جمع کرد.

## منابع فنی بیرونی — بررسی‌شده هنگام تهیه بسته

### R1 — اتصال OpenCTI

https://docs.opencti.io/latest/deployment/integrations/

برای اصل وجود GraphQL API، مسیر `/graphql` و احراز هویت token کاربر استفاده شده است؛ نه برای ادعای صحت queryهای نسخه خاص یا اتصال اجراشده.

### R2 — هویت و ادغام

https://docs.opencti.io/latest/usage/deduplication/

برای توضیح این نکته استفاده شده که سازوکار identity و deduplication پلتفرم به ویژگی‌های موجودیت وابسته است. نگاشت هویت این بسته یک قرارداد پیشنهادی است.

### R3 — پاسخ GraphQL

https://graphql.org/learn/response/

برای وجود حالت پاسخ دارای data و errors به‌طور هم‌زمان استفاده شده است. faultهای آفلاین این بسته شبیه‌سازی محدودند، نه آزمون اجرای واقعی یک endpoint.

### R4 — ارزیابی ایجنت

https://www.anthropic.com/engineering/demystifying-evals-for-ai-agents

به‌عنوان مرجع عمومی تفکیک task، trial و grader و استفاده از ارزیابی کدی، انسانی یا مدل‌محور آمده است. جزئیات کیس‌ها و آستانه‌های این بسته از آن مقاله کپی نشده‌اند.

### R5 — مدل محلی و tool calling

https://docs.vllm.ai/en/latest/features/tool_calling/

برای یادآوری وابستگی پشتیبانی ابزار به مدل/پیکربندی parser استفاده شده است. نمونه local_chat_agent.py در این محیط به یک مدل واقعی متصل نشده و نسخه سرور باید در محیط شما ثبت شود.

### R6 — STIX 2.1

https://docs.oasis-open.org/cti/stix/v2.1/os/stix-v2.1-os.html

مرجع قالب تبادل داده است. export این بسته از objectهای معمول و ویژگی‌های سفارشی x_benchmark استفاده می‌کند. اعتبارسنجی کامل انطباق و import روی OpenCTI در زمان ساخت انجام نشده است؛ کنترل JSON و reference integrity انجام شده است.

## وضعیت تاریخ و release

تاریخ تهیه نسخه: ۲۰۲۶-۰۹-۱۷. snapshot مصنوعی یک قرارداد ثابت با as_of مشخص دارد. هیچ release واقعی ATT&CK از تاریخ نام فایل استنتاج نشده است. لینک‌های latest ممکن است در آینده تغییر کنند؛ برای انتشار نتیجه عملی، نسخه یا commit منابع وابسته را pin کنید.
